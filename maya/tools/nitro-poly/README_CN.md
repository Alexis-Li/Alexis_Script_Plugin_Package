# NitroPoly

[English](README.md)

## 简介

NitroPoly 4.0.4 是在原版 NitroPoly 2.0 基础上重构优化的 Maya 多边形建模工具集，包含选择、拓扑、轴心、连接和循环边等常用功能。

脚本兼容 Python 2 和 Python 3，作者已在 Maya 2020、2022、2024 中测试。

## 安装方式

1. 关闭 Maya。
2. 将 `package/NitroPoly/scripts/NitroPoly.py` 复制到 `Documents\maya\scripts`。
3. 如果使用自用工具箱，也可以放入工具箱的脚本目录。

## 使用方式

1. 在 Maya 脚本编辑器的 Python 页运行
   `package/NitroPoly/scripts/NitroPoly_Start.py` 中的内容。
2. 经常使用时，可把启动代码保存到工具架或自用工具箱中。
