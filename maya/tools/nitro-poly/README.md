# NitroPoly

[中文说明](README_CN.md)

## Introduction

NitroPoly 4.0.4 is an optimized reconstruction of NitroPoly 2.0. It provides a
Maya polygon-modeling interface for selection, topology, pivots, connections,
and edge-loop workflows.

The tool supports Python 2 and Python 3 and has been tested by the author in
Maya 2020, 2022, and 2024.

## Installation

1. Close Maya.
2. Copy `package/NitroPoly/scripts/NitroPoly.py` to
   `Documents\maya\scripts`.

## Usage

1. Run the contents of `package/NitroPoly/scripts/NitroPoly_Start.py` in the
   Python tab of Maya's Script Editor.
2. Save the launch code to a shelf button if you use it frequently.
