# NitroPoly

[中文说明](README_CN.md)

## Introduction

NitroPoly 4.0.4 is a Maya polygon-modeling toolkit for selection, topology,
pivots, connections, and edge-loop workflows.

## Supported Versions

Python 2 and Python 3. Tested by the author in Maya 2020, 2022, and 2024.

## Installation

No installation is required. Open `scripts/NitroPoly.py` and run its complete
contents in Maya's Python Script Editor. The file can also be saved to a shelf
button or copied to Maya's `scripts` directory.

## Usage

Run `NitroPoly.py`, then choose an operation from the NitroPoly window.
