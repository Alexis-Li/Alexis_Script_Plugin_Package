# NitroPoly

[English](README.md)

## 工具简介

NitroPoly 4.0.4 是 Maya 多边形建模工具集，提供选择、拓扑、轴心、连接和循环边
等常用功能。

## 支持版本

兼容 Python 2 和 Python 3；作者已在 Maya 2020、2022、2024 中测试。

## 安装方式

无需安装。打开 `scripts/NitroPoly.py`，在 Maya Python 脚本编辑器中运行完整
内容。也可以将完整代码保存到工具架按钮，或把文件复制到 Maya 的 `scripts`
目录。

## 使用方式

运行 `NitroPoly.py`，然后在 NitroPoly 窗口中选择需要的操作。
