# ZiSpread

[English](README.md)

## 工具简介

ZiSpread 是原 64 位 C++ 插件的单文件 Python 重构版，可通过交互拖动均匀分布
所选环线。

## 支持版本

支持使用 Python 2 或 Python 3 且提供 Maya Python API 2.0 的 Maya 版本。

## 安装方式

无需安装。在 Maya Python 脚本编辑器中运行 `ZiSpread.py` 的完整内容，或将完整
脚本保存到工具架按钮。

## 使用方式

1. 选择需要均匀分布的环线。
2. 运行脚本。
3. 在视口中按住鼠标左键或中键横向拖动。
4. 松开鼠标确认；按 Ctrl+Z 撤销。
