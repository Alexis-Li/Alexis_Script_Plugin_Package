# ZiSpread

[中文说明](README_CN.md)

## Introduction

ZiSpread is a single-file Python reconstruction of the original 64-bit C++
plug-in. It evenly distributes selected edge loops through an interactive drag.

## Supported Versions

Maya versions using Python 2 or Python 3 and Maya Python API 2.0.

## Installation

No installation is required. Run the complete contents of `ZiSpread.py` in
Maya's Python Script Editor, or save the complete script to a shelf button.

## Usage

1. Select the edge loops to distribute.
2. Run the script.
3. Drag horizontally in the viewport with the left or middle mouse button.
4. Release to confirm; press Ctrl+Z to undo.
