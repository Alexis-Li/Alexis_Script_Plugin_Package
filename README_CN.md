# Alexis 脚本与插件合集

[English](README.md)

## 简介

这是一个面向 3D 美术工作者的 Autodesk Maya 脚本与工具合集，同时提供 Unreal Engine 插件工作区。

- [Flatten Mesh To UV](maya/tools/flatten-mesh-to-uv/README_CN.md)：把模型的 UV 展开结果转换为平面多边形。
- [NitroPoly](maya/tools/nitro-poly/README_CN.md)：Maya 多边形建模工具集。
- [ZiSpread](maya/scripts/zi-spread/README_CN.md)：通过鼠标拖动均匀分布所选环线。

## 安装方式

下载或克隆本仓库，然后进入所需脚本或工具的目录，按照其中的中文说明安装。
