# MtoU_LiveLink

[English](README.md)

MtoU_LiveLink 连接同一台电脑上的 Maya 与 Unreal Editor，让你在 Maya 中制作时，
直接在 Unreal 中查看角色动画、BlendShape 和服装修改效果。支持实时预览与动画
缓存播放，不会创建动画或预览资产。

## 兼容性

- 64 位 Windows
- Autodesk Maya 2024（当前工作流程）；继续支持 Maya 2022.4
- 官方原版 Unreal Editor 5.7.4
- Topia Engine 5.7.4（已验证插件编译与编辑器加载）
- 仅用于编辑器，不支持 PIE（Play In Editor）。

不保证兼容其他第三方修改版 Unreal Engine 5.7。Maya 与 Unreal 组件应使用同一版本。

## 安装

以下组件路径均相对于本产品目录。

**Maya**

1. 把 Maya 组件文件夹（`maya/MtoULiveLink/`，或 `MtoULiveLink-<版本>.zip`
   解压后的文件夹）放在一个长期保留的位置。
2. 打开 Maya，把文件夹中的 `install.mel` 拖入视口。
3. 在提示中确认。工具架上会出现 **MtoU** 按钮（已有按钮会沿用），点击即可打开。

安装会把这个文件夹登记为 Maya 模块（用户 Maya 目录 `modules` 文件夹中的
`MtoULiveLink.mod`，用户 Maya 目录通常是 `文档/maya`），之后不要移动或删除
该文件夹。文件夹路径包含中文等非英文字符时，Maya 无法从该路径加载，安装会把
工具复制到 `modules/MtoULiveLink`，原文件夹之后可以删除。发现不是用 `install.mel`
装上的旧版本（例如 Maya scripts 目录中的 `MtoULiveLink.py`）时，安装会列出
它们并询问，确认后删除，取消则不做任何修改。当前 Maya 已打开过旧版本时，
按提示重启 Maya。

**Unreal**

1. 将 `unreal/MtoULiveLink/` 复制到 `<Project>/Plugins/MtoULiveLink/`。
2. 编译 Unreal 项目。Topia Engine 用户请按下方说明操作。
3. 启用 **Live Link** 和 **MtoU_LiveLink**，然后重启 Unreal Editor。

**升级、回退与卸载**

Maya 与 Unreal 组件成对升级和回退：两端使用同一协议版本，混用时会在
触碰场景之前拒绝连接。先结束当前会话，然后：

- 升级：把新版 Maya 组件的 `install.mel` 拖入 Maya，替换 Unreal 插件，
  再重新连接。
- 回退：拖入上一版本 Maya 组件的 `install.mel`。上一版本没有 `install.mel`
  时，先删除下方卸载列出的文件，再按该版本的说明安装。最后恢复上一版本的
  Unreal 插件构建并重新连接。
- 卸载 Maya 组件：删除用户 Maya 目录 `modules` 中的 `MtoULiveLink.mod` 和
  `MtoULiveLink` 文件夹（如有），删除工具架上的 MtoU 按钮，然后重启 Maya。

### Topia Engine 5.7.4

**推荐：双击向导（Windows）**

关闭 Unreal Editor，确认项目 `Plugins/MtoULiveLink` 已放入源码插件。
双击仓库中的 `tools/build_mtou_topia_gui.cmd`，选择项目 `.uproject`，再选择公司引擎的
`Engine/Binaries/Win64/UnrealEditor.exe`。核对显示的路径后点击“确定”，等待成功提示再打开项目。
失败时将控制台中的错误及 `Build log` 路径交给技术同事。
若提示缺少编译器或 SDK，请由技术同事配置，
或提供与同一公司引擎版本匹配的已编译插件。
编译完成后会替换目标插件的编译产物。
如需单独复制向导，请将 `build_mtou_topia_gui.cmd`、`build_mtou_topia_gui.ps1` 和
`build_mtou_topia.ps1` 放在同一文件夹中。

**命令行方式**：关闭 Unreal Editor。将 `TOPIA_ENGINE_ROOT` 设为包含 `Engine` 的目录，
将 `ATHENA_UPROJECT` 设为目标 `.uproject`，然后在仓库根目录运行以下命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tools/build_mtou_topia.ps1 `
  -EngineRoot $env:TOPIA_ENGINE_ROOT `
  -ProjectFile $env:ATHENA_UPROJECT `
  -Apply
```

去掉 `-Apply` 可先检查路径并预览安装内容。

## 准备角色

- Maya 必须包含启用网格实际蒙皮所需的骨骼及完整祖先链，包括骨骼之间的中间
  分组，名称与父子关系应一致。同一短名出现在多个 Maya 分支时，支持同一父级下
  的 Unreal 导入数字后缀或 32 位 hash 后缀，并报告映射。无关的导出骨骼分支
  不会阻止连接；但每根 Unreal 骨骼只由一根 Maya 骨骼驱动，若同一父级下有两根
  Maya 骨骼发布同一名称，请在 Maya 中重命名其中一根。
- 预览服装时，准备与 Primary Driver 服装位置对齐的 **Preview Static Mesh**。
  服装与身体等非服装几何体应使用不同的导入材质槽。
- 预览 BlendShape 时，Maya BlendShape 与 Unreal Morph Target 需要名称匹配，
  并在 Maya 中开启“传递 BS”。

### 拆分角色部件

当同一个角色由多个 Skeletal Mesh 组成时，将服装数据来源指定为 Primary Driver，
其余网格添加到 Binding 的 **Additional Parts**。所有启用部件在同一个连接下摆姿和显示：

- 只有 Primary Driver 提供服装识别、权重转移和 **Preview Morph transfer**。
- 每个部件包含名称、Skeletal Mesh 和 **Enabled** 开关。所有网格必须共用同一个
  **Skeleton** 资产。各 LOD 实际蒙皮所需的共有骨骼及其完整祖先链，必须具有一致
  的层级和参考姿势。部件独有的次级骨骼即使不在 Primary 中，也会接收 Maya 动画；
  禁用部件不增加骨骼依赖。
- 新增服装及次级骨骼后，导入新服装、更新启用部件并重连。旧网格仅在自身绑定
  姿势或权重改变时需要更新。Maya 缺少必要骨骼或共有骨骼不兼容时仍会拒绝连接，
  并提示具体部件和骨骼。
- 只有某个部件拥有的 Morph Target 也会传输；多个部件同名的 Morph 会接收到
  相同数值。
- 新增、删除、启用、停用或替换部件都会结束当前连接，之后需在 Maya 中重连。
  已生成的服装预览会保留；Primary Driver、Preview Static Mesh、
  **Driver Garment Slot Override** 或相关导入数据变更后需要 **Refresh Preview**。
- 重命名部件或调整列表顺序无需重连。

## 首次连接

1. 在 Unreal 中创建 **MtoU_LiveLink Binding** 资产，指定
   **Primary Driver Skeletal Mesh**，并按需添加 **Additional Parts**。
2. 将 Binding 资产从内容浏览器拖入关卡，创建对应的 Binding Actor。
   细节面板默认展开 **MtoU · 运行状态**（分别显示预览与连接状态及下一步）、
   **角色组成**（主体和可展开的附加部件）和 **预览控制**（绑定资产、生成的网格、
   刷新、删除及缓存播放）。需要查看或选中完整诊断时，展开 **高级设置与诊断**；
   **复制完整诊断** 会复制包括镜头联动与场景参考详情在内的全部内容，便于报告问题。
   没有诊断时日常界面不会显示空白日志。
   连接状态在首次连接前显示“未连接”，流式连接中显示“已连接”，会话结束后显示
   “连接已中断”；中断后需在 Maya 重新连接。
3. 在 Maya 中点击工具架上的 **MtoU** 按钮，选择变形根骨骼，点击“设置角色”。
   顶部切换“动画”／“模型”，下方依次是连接控制（设置角色、连接、断开与连接
   状态）、场景信息（左列根骨骼、衣服、帧率；右列骨骼／BlendShape 数量与缓存；
   名称过长时会省略，悬停可看全文）、预览与播放（预览模式、传输上限，缓存按钮仅在
   缓存播放模式下出现）、镜头联动（一行状态、联动按钮与场景参考窗口）、工具
   （Display 和重名骨骼选择）、诊断（状态与诊断详情，其中 **复制完整诊断** 复制全部
   内容）。警告开关位于诊断卡片下方。
4. 选择“动画”，点击“连接”，指示变绿。在 Maya 中摆姿、拖动时间轴或播放
   动画，即可在 Unreal 中查看效果。预览行的“上限”用于限制实时传输帧率。
   不可用按钮会用提示说明原因。同一连接的相同警告只打断一次，新错误仍会
   弹出。

## 动画预览

使用“动画”模式实时预览角色。需要检查一段动画时，在 Maya 选择“缓存播放”。
关闭“自定义捕获范围”会使用当前播放范围；开启后输入整数开始帧和结束帧。
点击“捕获并上传”，等待缓存显示“已就绪”。捕获包含两个端点，范围与场景帧率
在开始时固定，不修改 Maya 的播放范围；支持单帧及负数起始帧。

在 UE Binding Actor 的“预览控制”中查看源帧范围、帧率、当前已应用源帧及状态。
点击“播放”从首帧开始，停止或播放结束后点击“再次播放”可回放保留的缓存。
“暂停”保留当前姿势与缓存，等待任意时长后点击“继续”从同一姿势接着播放，
不会补发暂停期间的帧。“停止”结束本次播放并保留缓存与最后姿势。需要检查某一帧
时，在“定位”旁的输入框填写整数 Maya 源帧后点击“定位”：UE 显示该帧并进入暂停。
输入格式无效或超出整数范围时，该行会提示错误。
只有本次捕获采样过的帧可用，未采样的帧会被拒绝，该行会给出请求帧与可用的源帧
范围。开启“循环”后，最后一帧播放完会回到首帧并显示当前轮次；关闭后完成当前轮。
定位与循环都复用已上传的缓存。自然结束停在最后一帧。在 Maya 再次点击“捕获并
上传”可准备新范围，旧 UE 播放会在采样前结束。切回 Maya 的“实时预览”会清除 UE
缓存并恢复实时姿势。断线重连后，若仍保留兼容的完整本地缓存，可点击“上传保留
缓存”。Maya 状态行显示捕获、上传、就绪、播放、暂停、定位、循环、停止和失败；
经过定位或循环轮次后结束的播放会显示为播放段完成，而不是整段缓存的一次完整回放。

单次捕获上限为 20,000 帧或 1 GiB，达到上限时请缩短范围。无效范围会在采样前
报错。采样或上传失败会返回实时预览并显示原因；回放失败时 UE 仍保留完整缓存，
可再次播放。

## 镜头联动预览

用这条工作流在 UE 的镜头与时间轴下检查 Maya 动画。它是可选的：不进入联动时，
实时预览、缓存播放和服装比较照常工作。

1. 在 Unreal 选中 Binding Actor，在 **镜头联动** 中点击 **配对为主角色**（该行
   随后显示“已配对为主角色”），并打开要跟随的 Level Sequence。
2. 在 Maya 照常连接角色，在主面板的 **镜头联动** 卡片点击 **进入联动**（也可在
   Unreal 详情面板点击 **进入联动**，Maya 会跟随任一端）。Maya 会停止自身播放，
   跟随 Sequence 时间与求值相机，并回传角色的完整姿势。
3. 两端都用一行状态显示联动情况，例如“镜头联动中 · Unreal 控制时间 · 同步正常”。
   Maya 跟不上时会显示“Maya 跟不上”和滞后时间；可暂停 Sequencer 等待 Maya 追上，
   或关闭占用性能的程序；经常出现时见[常见问题](#常见问题)。滞后的姿势不会被报成
   已同步。求值、样本与 revision 等读回值保留在 Maya 的诊断详情和 Unreal 的
   **高级设置与诊断** 中，可用 **复制完整诊断** 一并复制。
4. **返回实时** 会恢复 Maya 的时间轴、视图与门，并保持 Maya 暂停，Unreal 继续
   保持接管；Maya 播放由用户自行恢复。**结束预览** 另外把原 writer 交还给 Sequence，
   在 **返回实时** 之后仍可使用，直到交还完成。两个按钮在任一端都可操作。

联动期间，改动相机、暂停、cut 或明确跳转都会取消旧目标；相机随时间连续运动不会
取消已经在路上的回传。若目标的 writer 无法安全隔离，Unreal 会在写入前拒绝并说明
原因，而不是暂停整个 Sequence。进入联动前必须先清除缓存播放。恢复失败只在发生时
显示（Maya 显示“恢复失败”，Unreal 显示“恢复未完成”）：在 Maya 的诊断详情或 Unreal
的 **高级设置与诊断** 中查看未恢复的资源，按记录手动恢复（例如在 Maya 中解锁相机、
重设时间范围，或在 Sequencer 中检查对应轨道），也可以重新打开关卡。关闭或切换
Level Sequence、关闭其关卡或删除已配对的 Actor 都会结束联动：Unreal 交还 writer，
Maya 恢复自身状态。在 Maya 打开或新建
其他场景时，联动会先恢复开始时的场景，再断开连接。若联动驱动的 Maya 相机在联动
期间被删除或其相机 shape 被替换，Maya 会拒绝后续目标且不写入其他相机；结束预览
后重新进入联动即可使用当前相机。

## 副对象

在实时预览和镜头联动中，把一个独立的骨骼道具或第二个角色与主角色一起预览。
不设置副对象时，以上各工作流保持不变。

1. 为副对象放置第二个 Binding Actor，位置和旋转与主角色的 Binding Actor 完全
   相同；副对象自身的摆放来自它在 Maya 中的根骨骼。在它的详情面板 **镜头联动**
   中点击 **配对为副对象**。主角色的 Actor 需要用 **配对为主角色** 配对。
2. 在 Maya 主面板 **镜头联动** 卡片点击 **打开对象配对窗口**，选中副对象的根骨骼
   （它有多个 Display 控制器时一并选中要用的那个），点击 **设为副对象**。没有
   Display 控制器的道具也可以。
3. 照常连接。Unreal 以同一个 Maya 时间显示两个对象；镜头联动中，只有两个对象的
   全部显示都拿到新姿势时才一起显示。
4. 只想继续预览主角色时，在 Maya 窗口或副对象 Actor 的详情面板点击 **移除副对象**。
   Unreal 把副对象的轨道交还给 Sequence，副对象 Actor 不再跟随 Maya；主角色继续
   预览，不需要重新连接。

更换副对象、修改任一对象的骨架、衣服、Binding 或部件、对已连接集合中的 Actor
重新配对或解除配对，或删除已配对的 Actor，都会结束连接，需要重新连接。关卡中的其他
Binding Actor 不跟随 Maya。副对象 Actor 放在其他位置或在联动中被移动时，会以“副对象
与主角色在 UE 中的放置不一致”拒绝。缓存播放和模型工作流只支持单个角色，请先移除
副对象。若移除副对象时无法恢复它的轨道，连接会结束，两端都会说明需要手动恢复的
内容。

## Maya 中的场景参考

Unreal 可以把显式选择的关卡范围导出为静态参考几何，让 Maya 看到同样的环境。
参考只是显示辅助：任何预览工作流都不需要它，交接也从不包含图片数据。

1. 在 Unreal 的 **场景参考** 中选择关卡与子关卡并执行导出。Unreal 会报告结果，
   例如“已导出 152 个对象，可在 Maya 导入”，请求的子关卡未加载时也会说明。请先
   配对目标（见镜头联动），参考才能与它对齐。
2. 在 Maya 主面板的 **镜头联动** 卡片点击 **打开场景参考窗口**。窗口显示来源关卡与
   子关卡、规模（例如“152 个对象，约 120 万三角面”），以及交接是“可导入”、
   “已导入（时间）”还是“已过期，请在 UE 重新导出”。点击 **导入/更新参考**：Maya 会在
   触碰场景之前校验交接与规模上限，导入到自己的容器，并用一句话说明结果；丢弃节点、
   回滚与残留只在导入失败时列出。交接 ID、摘要、空间修订与上限在诊断详情中。
3. **移除参考** 只删除该容器；**恢复上次更新** 会完成或丢弃被中断的更新。若你把自己的
   对象放到了参考之下，或在其 `MtoU_UE_SceneRef` 命名空间中新建了对象，更新与移除都会
   被拒绝并列出该对象：把它移出参考和该命名空间后再试。

参考与角色、联动相机处于同一坐标系，因此会跟随被移动或旋转的目标。位置取自
Unreal 导出时已配对目标所在的位置。目标被移动或旋转之后，以及早期版本导出的
参考，需要重新导出并再次导入；若状态行提示清单未带锚点，参考会停在 Maya 原点，
直到重新导出。已导入的参考属于另一个摆放时，镜头联动不会开始（场景参考属于旧的共同
空间）：重新导出并导入，或点击 **移除参考** 后不带参考继续。

## 服装模型预览

1. 在 Unreal Binding 中指定服装 **Preview Static Mesh**。
2. 在 Binding Actor 上点击 **刷新预览**，等待预览状态显示已就绪、有警告或失败。
   失败时会显示中文原因，连接状态独立显示；展开 **高级设置与诊断** 可查看并
   复制原始错误。Driver 角色的其他部分仍会显示。
3. 在 Maya 中选择“模型”，确认服装和“传递 BS”设置，再点击“连接”。
4. 在 Maya 中给角色摆姿，检查 Unreal 中的服装变形。
5. 在 Binding Actor 的 **预览控制** 中点击 **显示原始服装**、**显示生成服装**，
   在相同姿势、Actor 变换、镜头和光照下比较；身体与启用的附加部件保持显示。
   此操作需要已就绪的 Generated Preview。按钮不可用时查看预览状态或悬停提示，
   按提示刷新或修正输入。失败或失效后显示“当前显示：原始角色”时仅供检查，不是
   模型对比结果。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| Maya 提示 MtoU_LiveLink 安装不完整 | 提示中写明了缺少的文件。重新完整解压 Maya 组件，把其中的 `install.mel` 拖入 Maya 视口，然后重启 Maya。 |
| 安装后点击 MtoU 仍打开旧版本 | 安装时当前 Maya 已加载旧版本，重启 Maya 即可。 |
| 骨架不匹配 | 先按详情中的根因排查：首个未映射骨骼的完整路径与父级、受阻的 Maya 后代与未访问的 Unreal 骨骼数量，以及提示的导入改名候选；若详情指出同一必要骨骼由两根 Maya 骨骼竞争，请在 Maya 中重命名其中一根。再检查 Maya 选择的根骨骼、层级，以及 Unreal Driver 网格是否为最新版本。 |
| 附加部件被拒绝 | 诊断信息会指出具体部件和原因。请检查是否共用同一个 **Skeleton** 资产、Maya 中提示的必要骨骼及父链是否完整，以及共有参考姿势是否一致。若无法读取蒙皮权重，保留 CPU 蒙皮数据后重新构建或导入网格。 |
| 预览刷新失败 | 检查网格对齐情况、服装与身体的材质槽是否分离，修正提示的问题后重新刷新。 |
| 有意减面的模型无法通过自动服装识别 | 检查源模型是否有重复几何体或服装／身体混用材质槽。确认是有意减面后，在 Binding 的 **Driver Garment Slot Override** 中指定服装独立的材质槽，再刷新并检查效果。 |
| BlendShape 未生效 | 检查“传递 BS”、名称匹配、当前服装及连接诊断。模型预览的源资产变更后需重新刷新。 |
| 镜头联动中经常显示“Maya 跟不上”和滞后时间 | 在 Maya 中打开 **窗口 > 设置/首选项 > 插件管理器**（英文界面：**Windows > Settings/Preferences > Plug-in Manager**），取消不用的插件的 **自动加载**，例如 MASH、XGen（`xgenToolkit`）、GPU Cache、Scene Assembly、LookdevX 和 Type，然后重启 Maya。打开场景时，场景需要的插件仍会加载。 |
| 修改后连接断开 | 更换服装、模式、“传递 BS”或角色部件后需重连；刷新也会断开当前连接。修改或重新导入 Primary Driver、Preview Static Mesh，或修改 **Driver Garment Slot Override** 后，刷新模型预览并重连；撤销／重做这些修改时也遵循同一规则。 |

预览时请保留 Binding Actor 并保持其关卡加载；删除 Actor 或卸载关卡会结束连接。
