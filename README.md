# Alexis Script & Plugin Package

[中文说明](README_CN.md)

## Introduction

A collection of Autodesk Maya scripts and tools for 3D artists, with workspace
support for Unreal Engine plug-ins.

- [Flatten Mesh To UV](maya/tools/flatten-mesh-to-uv/README.md) converts UV layouts into flat polygon geometry.
- [NitroPoly](maya/tools/nitro-poly/README.md) is a polygon-modeling toolkit for Maya.
- [ZiSpread](maya/scripts/zi-spread/README.md) evenly distributes selected edge loops with an interactive drag operation.

## Installation

Download or clone this repository, then open the README inside the script or
tool folder you want to install.
