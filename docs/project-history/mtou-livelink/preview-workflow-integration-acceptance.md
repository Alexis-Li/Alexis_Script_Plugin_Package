## I-3 修复

1. 目标移动后，旧场景参考仍能进入镜头联动；现以 `REFERENCE_STALE` 拒绝并保留旧参考。
2. 参考容器下用户挂接的场景节点，或用户在容器命名空间中新建的节点，会随更新／移除被删；现导入时在容器组记录所创建节点的 UUID，清单外的节点使更新与移除被拒绝并列出，过期暂存命名空间则整体保留并在恢复事件中列出这些节点。
3. Maya 读不出的 FBX 被当作空场景替换掉旧参考；现无几何的暂存被拒绝，旧参考保留。
4. 锁定输入使目标被拒后，恢复仍写回锁定属性并报告假残留；现只写回与捕获不同的值。
5. 生产序列循环回绕时，Sequencer 恢复接管前保存的动画实例且其 Live Link 求值已停止，副对象显示停在旧帧、屏障持续拒绝；现在持有接管期间，每次更新为集合内显示恢复 Live Link 求值。
6. UE 拒绝某一组后无人再回答该目标，显示要等到下次暂停或跳转；现 Maya 重新采样被拒绝的样本。

## 证据边界与遗留

- Topia 5.7.4 由用户自行构建验证，本次未执行；Topia 的支持声明沿用[原记录](topia-engine-acceptance.md)。
- 在含中文的路径下从源码编译 UE 插件失败（MSVC 无法打开该路径下的 PCH，C1083），属工具链限制；打包后的插件在含空格与中文路径的工程中可直接加载使用。
- Maya 2022.4 只做了安装检查与编译检查，未跑交互联动。
- 待验证风险（后续候选）：`GuiRegression` 以错误的服装槽重复调用刷新预览时，每次失败刷新后编辑器内存持续增长直至耗尽；基线代码相同。是否为失败刷新未释放中间网格尚未证实。
- 宿主运行由脚本在后台驱动真实 Maya GUI 与 UnrealEditor，不是人工点击；交互视口逐帧观测未做。
- 全部场景放进同一次 `ProductionSequence` 长运行时，中途整组重新连接后，Unreal 立即发起的联动曾得不到 Maya 确认而超时：Maya 发送线程在面板主线程安装监听前读到的 `mode_state` 被丢弃。现在这些状态语句会被保留，监听安装后按到达顺序先行交付；同一长运行在修复后通过（见 #59）。
